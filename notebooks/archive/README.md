# Research notebook archive

The scripts in `scripts/` and `src/` are the active reproducible interfaces. The notebook files here preserve the exploratory/modeling journey; none of the three model implementations has been removed.

- `training/`: earlier training/template entry points.
- `analysis/`: model comparisons, forward warning-policy analysis, error analysis and benchmark notebooks.
- Other notebooks in this folder: earlier targets, horizon experiments and feature-selection variants.

Use [the final showcase](../final_results.ipynb) for the comparative release. EDA remains unchanged under `../eda/`. Outputs saved in archived notebooks reflect their original research run and may use different targets or older code. File moves are listed in [the relocation map](../notebook_locations.json).
